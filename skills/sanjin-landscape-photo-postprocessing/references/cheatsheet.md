# 决策规则速查 — 《风光摄影后期基础》

| 能力 | 一句话规则 |
|---|---|
| 内容—形式—技术的修图意图诊断 | 先写清主体、主题、情绪和区域优先级，再决定任何技术或模型指令。 |
| 后期尺度与真实性边界 | 先分级改动尺度并写不可改项，超出现场事实时标注为合成或数码创作。 |
| 主题驱动的构图与视觉引导 | 先确认主体，再用元素取舍、反差、引导线、画框和空间线索组织视线。 |
| 局部处理的统一—变化流程 | 先统一冲突区域，再以多次小幅局部编辑突出主体并制造变化。 |
| 通透六要素排障 | 先分发闷与发灰，再只修主体、细节、黑白场、白平衡、纯度或饱和度中的缺项。 |
| 直方图驱动的影调塑造 | 先查亮暗截断和目标气氛，再设计黑白场、中间调与局部对比。 |
| 自然优先的色彩设计五步法 | 用主色、色相数量、配色关系、自然性和相对明度饱和度五项设计色彩。 |
| 空间、立体与质感塑造 | 空间看远近线索，体积看亮灰暗面，质感只增强真实纹理与光感。 |
| 技术校正、降噪、锐化与输出验收 | 先校正，再以真实细节为锚降噪，分基础/创意/输出三次锐化并放大验收。 |
| 六类合成的适用条件与顺序 | 根据记录缺口选择曝光、接片、景深、堆栈、焦段或时间合成，并先合成后调色。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
