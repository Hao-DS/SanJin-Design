# 质量门禁

逐项检查全画幅。任一核心项失败时先定向修订，再考虑交付。

## 核心项

- **形式—情感关系**：能说清人物试图用什么秩序包裹何种失落、归属、身份或记忆；不是只有对称和粉彩。
- **构图**：中轴或网格一眼可读；垂直线稳定；没有无意的倾斜、裁切或透视扭曲。
- **画幅**：比例服务年代、叙事层级、横向队列或人物陈列；不是随意选择。
- **色彩**：3–6 个高明度、高饱和马卡龙色清晰分离；彩色覆盖约 60–85%；至少两个主色块各占约 15–35% 并形成粉×青绿、黄×蓝、酒红×薄荷绿或等效的大面积撞色。奶油色负责分隔，不得以灰褐色统一画面。
- **空间**：建筑构件形成重复节拍；前景清晰；装饰服务结构而非填满画面。
- **人物**：数量克制；每人有功能动作或明确视线；表情冷静；固定服装、制服或工具支持身份，不是随机戏服。
- **档案道具**：重要物件说明人物保存、分类、失去或坚持什么；不存在纯填充式复古杂物。
- **叙事**：一句话能说清；至多一个荒诞/仪式锚点；若有章节、档案或舞台框架，在缩略图下仍能读懂主要关系。
- **光线**：柔和均匀，明暗反差中等、色相反差鲜明；无硬闪光、灰雾、霓虹溢色、HDR 或商业棚拍亮泽。
- **表面**：哑光、轻微年代磨损、细颗粒；无塑料 3D、游戏引擎或过度锐化质感。
- **肤色与阴影**：肤色温暖通透；阴影沿所在色区加深而不是统一灰褐罩染；不存在灰脸、脏黄皮肤或浑浊黑位。
- **情绪**：通过空间距离、视线、停顿、手势或物件缺口表达；高饱和色与克制情绪形成反差，但没有广告式温情或直白煽情。
- **文字**：没有随机可读文字、乱码、logo 或水印；必须文字已经逐字核验或留给后期。
- **原创性**：未复用参考图的独特人物组合、红伞、长颈鹿、行李墙、六房间网格、法文标牌或具体布局。

## 常见失败与修订方向

| 失败 | 优先修订 |
| --- | --- |
| 只是“复古”但不像该系统 | 强化正面机位、中心轴、色块分区和重复建筑构件 |
| 只有形式，没有情感 | 选择一个情感发动机，为制服、任务、道具缺口和构图偏差赋予同一叙事作用 |
| 对称得像死板目录 | 保留轴线，在一个人物动作、道具角度或尺度上制造小偏差 |
| 画面偏灰、发闷或浑浊 | 删除 muted/faded/gray wash 等指令；提高粉、青绿、黄、蓝、酒红的色相纯度与明度；明确两块以上大面积撞色和暖肤色 |
| 画面过甜或幼稚 | 保留高饱和度；用奶油分隔、深色结构线和更严肃的人物动作稳定画面，不要退回灰色 |
| 画面太奢华或商业 | 保持鲜明色块，改用哑光旧材质、降低镜面高光、移除金色堆砌与潮流家具；不要靠降饱和解决 |
| 撞色变成碎彩噪声 | 合并近似颜色，把颜色集中到 2–4 个建筑/家具大面，每个主色块占据清晰面积 |
| 人物像摆拍 | 给每人一个功能动作，改变视线，不让所有人看镜头 |
| 角色没有身份 | 为角色确定重复服装、头衔、团队、工具与一件档案道具 |
| 荒诞太吵 | 删除次要奇观，只留下一个被严肃对待的异常物 |
| 场景杂乱 | 合并小物色彩，移除无功能装饰，让大色块和建筑先读 |
| 文字污染 | 清除标牌内容；需要文字时留干净区域后期排版 |
