# 叙事与情感系统

## 核心命题

把风格理解为一种矛盾：**人工化秩序正在容纳无法被整理的人生**。画面的几何、色彩、制服、档案和礼仪越精确，人物未说出口的失落、嫉妒、归属焦虑或时代终结就越有重量。不要用粉彩和对称替代这一层。

## 情感发动机

每张图选一个，不要混成主题清单。

| 发动机 | 可见线索 | 避免 |
| --- | --- | --- |
| 失去与保存 | 空座、缺失标签、反复擦拭的物件、保存完好的信件、过时仪式 | 墓碑、眼泪、直白悲伤符号 |
| 秩序与混乱 | 清单、队列、分类柜、时间表；一件物或一个人轻微偏离 | 全面灾难、满地混乱、无因破坏 |
| 破碎家庭与临时共同体 | 制服团队、共同任务、规章、集体餐桌；成员之间保持距离 | 强行温馨拥抱、广告式团队笑容 |
| 身份与自我表演 | 固定服装、头衔、徽章、精心维护的工具或名片 | 泛化“怪人”、无来由戏服 |
| 记忆与重述 | 书页、舞台、电视框、档案盒、照片或模型中的第二层故事 | 复杂到无法一眼读懂的多重画中画 |
| 时代终结 | 老机构、褪色招牌、关闭的窗口、仍被遵守的礼节 | 纯怀旧美化；要让消逝可见 |

## 叙事框架

- **章节页**：一个场景像精装书中的一章；边框、页码区或标题区可存在，但无用户文案时保持空白。
- **档案条目**：人物和物件被编号、分类、正面陈列；一个缺失项构成情绪。
- **回忆转述**：通过模型、褪色照片、画框或室内小舞台提示“这是后来被重新布置的过去”。
- **舞台中的舞台**：幕布、演播室边缘、绘景或剖面结构暴露虚构机制；不要追求无缝现实。
- **并行小传**：格间中的人物分别执行日常动作，共同主题通过颜色、时间和道具连接。

单张图最多使用一个主框架和一个弱次框架。

## 人物机制

- **不成熟的成年人**：借规则、俱乐部、制服或头衔保护脆弱自我；用小动作表现竞争、嫉妒或渴望认可。
- **早熟的儿童**：行动明确、表情冷静、装备准备充分；不要把儿童处理成天真装饰。
- **替代家庭**：传统关系可能缺席或失衡，团队通过共同任务维系。成员不必亲密，但需要依赖彼此。
- **情感表达**：停顿、视线错开、手部动作、物件交接、座位距离和重复礼节优先于哭泣、拥抱或夸张表情。

## 幽默机制

幽默来自反差，而不是搞怪堆砌：用极严肃的程序处理荒谬事件；让成年人为小礼节争执，却忽略更大的危机；让一个不合理计划被迅速、专业地执行；让复杂情感被压缩成一个普通动作。暴力、死亡或灾难不是默认笑点，也不应为了“黑色幽默”无端加入。

## 一句话故事公式

```text
[一个角色/临时共同体] 在 [人工化空间] 中执行 [具体任务或礼仪]，试图维护 [身份、关系、记忆或秩序]；[一个物件、空位、动作或偏差] 安静地揭示他们无法解决的问题。
```

例：一家即将停业的海滨电报局仍按旧规程为最后一位顾客盖章；墙上整齐挂着十二把钥匙，唯独第七码为空。
