# B端组件选型与使用规范

本文件是**场景词典**，不代表某一实现库的实际组件 API。实现时先确认技术栈（未选择则默认 Semi Design），再通过对应 MCP 取证后选型。

## 选型总原则

1. 优先选择用户已熟悉的控件，不为视觉新颖引入自定义交互。
2. 当选项少、互斥且需要立即比较时使用单选类控件；选项多、支持检索或异步加载时使用选择器。
3. 当用户需要比较大量结构化对象时使用表格；需要阅读连续内容时使用列表；需要快速概览时使用卡片。
4. 弹层只承载临时且可快速完成的任务；复杂任务进入独立页面、抽屉或分步流程。
5. 仅实现用户明确要求的业务状态；组件自身的 hover、focus、disabled 遵循所选组件库默认行为。

## 筛选与查询

| 场景 | 推荐模式 | 使用规范 | 禁止或避免 |
| --- | --- | --- | --- |
| 单一关键字检索 | 搜索输入 | 明确搜索对象；保留已输入内容与结果数 | 用 placeholder 代替字段标签 |
| 少量固定条件 | 行内筛选表单 | 常用条件前置，查询和重置相邻 | 将所有字段默认平铺 |
| 多维复杂条件 | 筛选面板 / 高级筛选 | 条件分组、支持增删条件、展示生效条件 | 把筛选范围隐藏在图标内且无状态提示 |
| 时间分析 | 日期/日期范围 | 说明时区、粒度、相对/绝对时间 | 混用不同图表的时间范围 |
| 层级组织或数据域 | 树选择 / 级联 | 展示已选路径，支持搜索 | 用扁平 Select 呈现深层结构 |
| 已选条件回显 | 筛选标签/条件摘要 | 可单项移除、可一键清空 | 只在弹层内部显示当前筛选 |

## 数据展示与操作

| 场景 | 推荐模式 | 关键规则 |
| --- | --- | --- |
| KPI | 指标卡 / Statistic | 只突出与决策有关的指标；附比较基线、趋势或解释入口 |
| 数据趋势 | 折线 / 面积图 | 时间维度连续；多序列保持可辨识颜色、线型或标签 |
| 分类对比 | 条形 / 柱形图 | 优先按数值排序；类别过多时使用 Top N + 明细 |
| 构成 | 堆叠条形 / 饼图 | 饼图不超过 8 类；小扇区不要承担精确比较 |
| 结构化明细 | 表格 | 定义列优先级、固定列、筛选排序、密度和数据量策略 |
| 对象详情 | Descriptions + 分区 Card / Tabs | 先展示摘要，再按任务拆分细节 |
| 时间事件 | Timeline | 用于事件顺序和审计，不用于高密度数值比较 |
| 数据质量 / 状态 | Badge / Tag + 文本 | 状态文案优先，颜色只作辅助；重要异常提供详情 |

## 表格场景矩阵

| 任务 | 必需能力 | 推荐补充 |
| --- | --- | --- |
| 查看与比对 | 列名、单位、对齐、排序、固定表头 | 列宽调整、列显隐、密度切换 |
| 查找对象 | 搜索、条件筛选、结果数 | 保存筛选、历史条件 |
| 批量处理 | 行选择、已选数、批量操作、取消选择 | 操作前预览影响范围 |
| 编辑数据 | 明确编辑态、校验、保存/取消 | 行内编辑只用于少字段低风险修改 |
| 分析明细 | 固定识别列、横向滚动、钻取入口 | 汇总行、导出、虚拟化 |

### 表格列优先级

- **P0**：对象识别、当前状态、主指标、必要操作；窄屏与滚动时保持可见。
- **P1**：比较和决策需要的辅助指标；默认可见，可横向滚动。
- **P2**：审计、备注、低频属性；支持列设置或详情查看。

## 表单与配置

| 场景 | 推荐模式 | 关键规则 |
| --- | --- | --- |
| 新建 / 编辑对象 | 标准表单 | 标签写清字段含义；必填、格式和依赖关系即时反馈 |
| 复杂规则配置 | 分区表单 / 分步流程 | 每步可返回；在提交前给出摘要和影响范围 |
| 批量导入 | 上传 + 字段映射 + 校验结果 | 明确模板、进度、错误行和可下载修正结果 |
| 高风险设置 | 表单 + 变更预览 + 确认 | 显示原值/新值、对象范围、不可逆影响 |
| 轻量参数调整 | Popover / 行内编辑 | 不超过少量字段；失败时不丢失输入 |

## 反馈、确认与导航

| 场景 | 推荐模式 | 规则 |
| --- | --- | --- |
| 即时非阻断成功 | Message / Toast | 说明完成对象，可撤销时给出撤销 |
| 需要用户关注 | Alert / Banner | 解释影响、推荐动作与详情入口 |
| 不可逆 / 高风险操作 | Dialog | 明确对象数量和后果，主按钮使用动作动词 |
| 上下文编辑 | Drawer | 保持主页面上下文；关闭时处理未保存内容 |
| 多步骤任务 | Steps | 每步名称可理解；失败处可定位修复 |
| 系统级异步状态 | Notification / 任务中心 | 保留可追溯记录，不能只靠自动消失的 Toast |

## AI 专用结果组件

| 场景 | 推荐模式 | 最低要求 |
| --- | --- | --- |
| 回答与分析结论 | AI 结果卡 | 来源、时间范围、生成标识、编辑/复制/继续追问 |
| 引用证据 | 引用列表 / 可展开引用 | 显示数据源、字段/片段、更新时间和权限可见性 |
| 图表建议 | 图表卡 + 筛选条件 | 指明 AI 使用的指标、维度和过滤条件 |
| 计划执行动作 | 操作预览 + 确认 Dialog | 展示影响对象、权限、是否可撤销 |
| 长任务 | 任务进度卡 | 阶段、耗时、取消、失败恢复和结果入口 |

## 组件状态矩阵

| 状态 | 用户应看到 | 用户可执行 |
| --- | --- | --- |
| 默认 | 值、标签、上下文与可用操作 | 正常交互 |
| Hover | 可点击/可编辑反馈，不改变语义 | 预览或点击 |
| Focus | 清晰焦点描边与键盘操作提示 | 键盘激活、移动、关闭 |
| Disabled | 原因或获取条件 | 不可触发；必要时给出原因 |
| Loading | 正在处理的具体对象/区域 | 等待或取消长任务 |
| Empty | 当前区域目的与下一步 | 创建、导入、调整条件 |
| Error | 出错位置、原因和恢复方式 | 重试、修正、查看详情 |
| No permission | 受限对象和申请路径 | 申请权限或切换范围 |
