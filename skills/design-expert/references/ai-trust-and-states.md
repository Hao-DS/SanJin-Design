# AI 数据助理：信任、控制与状态规范

适用于 AI 问答、指标解释、自动洞察、报告生成、自然语言查询、智能筛选和可执行代理。

## 五项硬规则

1. **人掌握决策权**：AI 只能建议、草拟、分析或执行经确认的动作，不替用户做高风险判断。
2. **结果可验证**：AI 结果显示数据来源、时间范围、指标口径、筛选条件和关键假设。
3. **结果可修正**：用户可编辑、重新生成、调整条件、追问、撤销或拒绝结果。
4. **风险有边界**：修改数据、权限、配置、自动任务、导出或对外发布前，展示影响范围并明确确认。
5. **失败可恢复**：失败、超时、无数据、无权限和低置信度有不同解释与下一步，不能只显示“生成失败”。 

## AI 生命周期

| 阶段 | 应展示什么 | 用户控制 |
| --- | --- | --- |
| 初次使用 | 能力范围、限制、示例任务、数据可访问范围 | 示例提示词、隐私/权限说明 |
| 输入前 | 当前上下文、已选数据集/对象、可用指令 | 修改范围、清除上下文、选择模板 |
| 生成中 | 当前阶段、处理对象、预估/已用时间 | 取消、后台运行、查看中间步骤（适用时） |
| 生成完成 | 结果、来源、时效、假设、AI 标识 | 编辑、复制、保存、继续追问、重新生成 |
| 需要确认 | 动作预览、对象数量、权限、后果 | 确认、返回修改、取消 |
| 失败或不确定 | 失败类型、未完成范围、建议恢复动作 | 重试、调整条件、查看详情、转人工 |

## 结果卡规范

### 基础结构

1. **结果标题**：明确任务，例如“按区域汇总近 30 天投诉率”。
2. **生成标识**：以文本/图标标识“AI 生成”，不伪装成人工结论。
3. **主要结果**：文字、指标、图表、表格或可执行建议。
4. **依据层**：来源、更新时间、时间范围、口径、筛选条件、数据缺口。
5. **操作层**：编辑、继续追问、重新生成、复制、保存/导出。
6. **风险层**：置信不足、可能过期、权限受限、待确认等。

### 来源与时效

- **硬规则**：数据型结果至少显示数据源名称、最近更新时间、查询时间范围和主要筛选条件。
- **硬规则**：若来源不可见、无权限或不完整，不能将结果表述为完整结论。
- **推荐规则**：引用可展开到字段、指标口径、关联报表或数据资产详情。
- **推荐规则**：对混合实时与离线数据的结果，分别标明刷新时点。

## 交互模式

### 对话 + 结构化结果

适用于探索性提问。对话区保持简洁，结果区优先使用图表、表格、KPI 或过滤条件卡，而非长段文本。

### 侧栏 Copilot

适用于页面内解释、辅助筛选、配置建议。不得遮挡当前任务的关键字段和主操作；要显示引用的当前页面/选中对象。

### 分屏分析工作区

适用于多轮数据分析。左侧保留问题与上下文，右侧固定展示可验证的数据结果。用户可将结果转为报表、保存视图或导出。

### 代理执行

适用于可调用工具的自动化任务。分为“计划 → 影响预览 → 用户确认 → 执行 → 审计记录”五步。任何一步失败都必须可以定位、重试或退出。

## 失败状态细分

| 类型 | 说明文案应包含 | 恢复动作 |
| --- | --- | --- |
| 无匹配数据 | 生效条件、数据范围、无匹配说明 | 修改筛选、扩大时间范围、清空条件 |
| 数据过期 | 最后更新时间、可能影响 | 刷新、查看数据质量、继续使用并标记 |
| 无权限 | 受限数据/操作与申请方式 | 申请权限、切换数据范围 |
| 模型或工具失败 | 未完成的阶段，不泄露内部错误细节 | 重试、保存输入、改用手动流程 |
| 结果不确定 | 不确定来源、缺失条件、建议验证方法 | 补充上下文、查看引用、人工核验 |
| 需要确认 | 将要执行的动作、对象数、不可逆后果 | 确认、修改、取消 |

## AI 文案

- 使用中性、任务导向语言：`正在分析`、`已基于以下数据生成`、`请确认后执行`。
- 避免拟人化或能力夸大：不用“我理解”“我保证”“一定正确”。
- 将结论与证据分开：先给摘要，再提供可展开的来源和假设。
- 错误信息先说影响和恢复方式，再提供技术详情入口。

## 验收检查

- [ ] 首次使用说明 AI 的能力范围与限制。
- [ ] 每个数据型结果有来源、时效、口径或数据范围。
- [ ] 用户可以在不重启流程的情况下编辑、修正或重新生成。
- [ ] 高风险操作在执行前展示影响范围和确认入口。
- [ ] 所有失败类型有差异化说明和恢复路径。
- [ ] AI 内容、状态和风险不只依赖颜色。
- [ ] 对话 UI 若落地实现：已按需对照 `companions/ant-design-x/components.md` 选型（或等价模式）。
