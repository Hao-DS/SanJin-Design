# 视觉系统：六变量控制

先锁定色彩、光线与绘制媒介，再处理构图、细节和情绪。六项不是独立滤镜；它们必须解释同一个夏日光照与手绘空间。

## 1. COLOR 色彩

- 主空气色：清澈 cyan、azure、turquoise blue。室外通常覆盖天空与远景；室内进入窗面、玻璃、白墙和阴影。
- 主自然色：fresh yellow-green、leaf green、emerald、mint。亮部偏黄绿，背光和深部偏青绿。
- 主光色：warm cream、lemon yellow、soft gold。落在人物轮廓、树干、墙面、桌面和草坡上。
- 辅助反光：peach、coral、pale pink、lavender，只占小面积，用于云、皮肤、白衣和环境反射。
- 深色不是黑：以 deep teal、blue-violet、indigo green 代替纯黑和灰褐。整帧近黑面积通常控制在约 0–3%。
- 高明度不等于发白；青空、黄绿与奶油光必须保持可读色相，不能被统一的白雾或粉彩蒙版洗平。

## 2. LIGHT 光线

- 一个明确的上午或下午主光方向，通常为侧光、侧逆光或逆光。
- 同时存在暖色直射光和冷青环境阴影；不要把阴影做成减亮后的灰色。
- 植物场景加入斑驳叶影，人物/动物/建筑边缘可有温暖轮廓光。
- 高光可略微溢出并带轻 bloom；只影响最亮边缘，不得抹掉五官、云体、白墙或器物结构。
- 空气中可有淡水汽、热浪、薄雾或发光尘粒，但必须轻、透明、有方向，不能成为特效层。

## 3. PAINT 绘制媒介

- painterly digital illustration + hand-painted animation background + gouache-like opaque brushwork。
- 先以大色块概括天空、树冠、建筑、衣物与地面，再以中等色块建体积，最后只在焦点放少量亮色碎笔触。
- 保留自然刷痕、覆盖式色块和略不完美边缘；纹理跟随形体或光向，不用随机噪点冒充手绘。
- 可以混合轻微粉彩、丙烯或油画覆盖感，但整体应轻盈，不得厚重、泥泞或浮雕化。

## 4. DETAIL 细节层级

- 焦点：轮廓干净、结构可信、少量关键细节清楚。
- 中景：用色块、遮挡与少数结构线说明空间。
- 远景：降低对比、饱和度和边缘锐度，以青色空气透视合并细节。
- 植物以树冠/枝组/叶簇为单位，通常先大块、再中块、最后零星亮叶；不逐片描绘。
- 人群、窗格、货架、砖、草、毛发与云纹都只保留识别所需的信息。

## 5. COMPOSITION 构图

- 竖幅优先使用低机位或略低视点，让树、人物、动物和建筑向晴空展开。
- 室外场景的天空/发光空气通常占 35–65%；纪念性树木、动物或山景可接近 70%，街景可降低。
- 建立前景遮挡、中景主体、远景天空/建筑/山体三层；焦点通常位于三分线或略偏中心。
- 留白是真实构图要素，不用云、飞鸟、招牌或装饰填满每一处。
- 透视保持可信，但不强调极端广角、镜头畸变或摄影景深。

## 6. MOOD 情绪

- 基础情绪：peaceful summer day、quiet happiness、nostalgic youth、fresh air、gentle breeze、warm everyday life。
- 叙事是一个没有强冲突的普通瞬间：散步、喝咖啡、等待、交谈、看风景、整理植物、休息或与动物相遇。
- 怀旧来自色光、动作和空间，不来自复古滤镜、胶片划痕或年代道具堆砌。

## 人物造型附加规则

- semi-realistic animation character，比例接近真人；明确为成年人时不得幼态化。
- 眼睛略简化但不过分放大；鼻口克制，皮肤以柔和色块塑造，允许暖腮红与青色反光。
- 发丝以大形和少量方向性碎笔触组织，衣褶只保留动作和体积所需线索。
- 姿势自然、重心可信、手部与物件接触正确；避免广告模特姿态、强修容、湿亮塑料皮肤和萌系表情。

## 可安全改变的变量

可改变主体、季节内的具体时段、地点、服装、建筑类型、植物种类、动物、道具、画幅与视点。改变后仍必须保留：高明度青蓝—黄绿—暖黄光色关系、暖直射光/冷环境影、水粉式手绘媒介、由实到虚的细节层级，以及安静日常情绪。
