## 固定搭配

- 人物肖像：04 + 02；需要更大天空时加 08。
- 街景/小店：02 + 06；需要群体尺度可加 04。
- 树木/仰拍：01 + 05；需要人物尺度可加 02。
- 山景/开阔自然：05 + 01；包含动物时加 08。
- 住宅/建筑：06 + 01；强调暖冷材质时可加 03。
- 静物/饮品：03 + 07；需要人物生活感时可加 02。
- 动物场景：08 + 05；森林关系可改用 08 + 01。
- 室内植物：03 + 06；第二张只提供叶影和暖冷关系，不复制房屋。

使用时明确声明：“这些图片是抽象风格参考，不是编辑目标；只学习媒介、光色、笔触、边缘、空间和情绪，不复制其中的主体、身份、地点、物件组合或构图。”生成后的质量判断应回看所选参考的光色关系、手绘媒介、细节梯度和空气感，而不是只比较是否出现蓝天或绿色植物。
