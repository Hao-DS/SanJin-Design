# 质量门禁

逐项检查全画幅。先过三个硬门禁：参考实际附加、媒介身份正确、光色关系成立。任一失败都不得因主题或局部细节正确而直接交付。

## 核心项

- **参考使用（硬门禁）**：生成时实际附加了 2–3 张题材或问题相近的 `style-references`，并明确标为风格参考；若当前工具不支持输入参考图，已向用户说明稳定性限制。
- **媒介身份（硬门禁）**：缩略图下应一眼读作手绘动画背景/水粉式数字插画。可见不透明色块、自然刷痕、轻微手工边缘和选择性细节；不得像照片、生活方式广告、房地产效果图、赛璐璐截图、光滑商业插画或 3D 游戏渲染。
- **光色关系（硬门禁）**：清澈青蓝空气、鲜亮黄绿、奶油暖光和冷青环境阴影必须同时可读；阴影不灰黑，亮部不被白雾洗平。
- **焦点与构图**：只有一个主要焦点，比例服务题材；前中后景清楚，偏中心/三分布局有呼吸，室外天空或空气面积合理，非机械套用。
- **光线结构**：主光方向明确，轮廓光与斑驳叶影有物理依据；bloom 轻微，五官、白墙、云和器物边缘仍有结构。
- **笔触层级**：大色块先于纹理；中景合并，远景软化。树叶、草、云、砖、木、毛发和皮肤没有逐个微描。
- **人物与动物**：比例、重心、关节、手部接触和动物解剖可信；人物不过度幼态化、大眼化、塑料化或时尚摆拍化。
- **日常情绪**：场景安静、有微风和生活动作；不靠史诗奇观、强冲突、煽情表情或广告式快乐制造情绪。
- **文字**：无随机文字、乱码、logo、水印或签名；用户要求的短文字已逐字核对，或已预留后期排版区。
- **原创性**：未重演参考图里的具体人物、绿色服装、店面、住宅、大树、山腰白屋、咖啡杯、西瓜静物、长颈鹿/大象/斑马组合、云形或构图。

## 常见失败与优先修订

| 失败 | 优先修订 |
| --- | --- |
| 像照片或房地产/咖啡店广告 | 删除镜头、真实曝光和微材质语言；要求整帧重绘为 gouache-like hand-painted animation illustration，简化砖、路、玻璃、商品和叶片 |
| 像硬边赛璐璐动漫 | 降低线稿和硬阴影，增加不透明色块覆盖、方向性刷痕、软硬边变化与背景绘画感 |
| 像精致游戏概念原画 | 删除 epic、ultra detailed、cinematic masterpiece；扩大天空/留白，合并材质，降低远景细节与戏剧冲突 |
| 画面灰、暗、脏 | 恢复清澈青空、鲜黄绿和奶油暖光；把灰黑阴影转为青绿/蓝紫，移除全局灰雾与褐色调色 |
| 蓝绿过于单一 | 在可见受光面加入奶油黄/金黄，在白物和皮肤加入少量桃粉/淡紫反光，保持分区而非统一滤镜 |
| 过曝或满屏 glow | 降低 bloom 和雾；恢复面部、云、白墙与器物结构，只在最亮边缘保留溢光 |
| 背景和焦点同样锐利 | 合并中景小物与叶簇，降低远景对比和饱和度，把细线和亮色碎笔触集中到焦点 |
| 人物太萌、太塑料 | 缩小眼睛、恢复真人比例与成年身份，改用色块皮肤、克制高光和自然生活动作 |
| 场景太满 | 删除无叙事功能的飞鸟、云、招牌、盆栽和小物，保留一个焦点、1–4 个生活锚点和清晰留白 |

## 一次修订顺序

1. 参考图未附加或角色混淆：先修输入配置。
2. 媒介不对：先把整帧变成水粉式手绘动画插画。
3. 光色不对：恢复青蓝—黄绿—暖黄和冷青阴影。
4. 空间不透气：调整天空/留白、前中后景和远景软化。
5. 细节过多或过少：只在焦点恢复识别所需信息。
6. 局部解剖、文字与溢光：最后修具体缺陷。

## 交付前记录

记录：输入角色、实际附加的 2–3 张风格参考、场景配方、六变量取值、三个硬门禁结果、画幅理由/像素、编辑保留项、一次主要修订，以及未解决限制（如有）。
