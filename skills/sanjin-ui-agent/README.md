# SanJin-UI-Agent

B 端数据中台、BI、运营后台和 AI 数据助理界面设计技能。

默认流程：理解需求 → 在 Figma 产出静态设计稿 → 人工评审与修改 → 明确确认当前版本 → 按确认稿搭建并验证交互页面。未确认时停在设计稿交付。

明确要求正式设计需求、规范或交付说明时走标准模式，另产出对应文档。阶段与门禁以 references/pipeline.md 为准；详细入口见 SKILL.md。

设计阶段使用 Figma 技能与 references/DESIGN.md；实现阶段再使用组件取证、scaffold/、交互验证脚本。不要以可运行代码页面代替 Figma 设计稿。
