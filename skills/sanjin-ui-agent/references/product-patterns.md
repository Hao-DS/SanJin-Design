# B端数据与 AI 产品模式

本文件定义页面级模式，不定义任何组件库 API。涉及实现时，必须由**当前选定实现栈**（未选择则默认 Semi Design）的 MCP / 物料验证实际组件。

## 规则分级

- **硬规则**：安全、可访问性、数据理解与任务可恢复的底线。
- **推荐规则**：默认采用；有明确业务理由时可调整。
- **可选模式**：适用时使用，不作为默认结构。

## 数据中台 / 数据工作台

### 页面框架

| 区域 | 内容 | 规则 |
| --- | --- | --- |
| 全局上下文 | 页面标题、数据域/项目、更新时间、全局筛选、保存视图 | 硬规则：显示筛选生效范围与数据时间 |
| 核心工作区 | 任务相关的指标、列表、图表或编辑区域 | 推荐规则：每个工作区只服务一个主要任务 |
| 侧边详情 | 字段说明、血缘、质量、权限、操作记录 | 可选模式：适合不离开当前上下文的深度查看 |
| 反馈区域 | 任务进度、校验、异步任务、异常和成功提示 | 硬规则：长任务展示可理解的阶段与恢复入口 |

### 常见任务

| 任务 | 推荐结构 | 关键约束 |
| --- | --- | --- |
| 数据资产检索 | 检索条件 + 结果表格 + 详情抽屉 | 结果显示命中数、数据域、更新时间和权限状态 |
| 任务配置 | 分步配置或表单 + 运行预览 + 校验反馈 | 先校验再执行；危险配置展示影响范围 |
| 数据质量监控 | KPI + 异常趋势 + 规则明细 | 状态不可仅靠红绿颜色；异常应能进入根因详情 |
| 数据权限管理 | 成员/角色表格 + 资源范围 + 操作日志 | 变更前后范围可比对；高风险授权二次确认 |

## BI 报表 / 数据看板

### 信息层级

1. **概览**：3–5 个与用户决策直接相关的 KPI，包含名称、值、比较基线、趋势和更新时间。
2. **解释**：趋势、比较、构成或异常图表；每张图明确回答一个问题。
3. **明细**：可筛选、排序、分页或虚拟化的表格，支持从图表钻取。

这是一条**推荐规则**。若用户的主任务是处理明细队列，表格可成为首屏主体，但仍要保留数据范围和关键状态。

### 筛选与钻取

- **硬规则**：全局筛选必须显示作用范围；模块级筛选必须紧贴受影响模块。
- **硬规则**：筛选条件、数据范围、指标口径和更新时点需要在用户可见处说明。
- **推荐规则**：按“时间 → 组织/对象 → 业务状态 → 高级条件”排序筛选；提供重置入口。
- **推荐规则**：图表钻取后保留来源图表的筛选上下文，并提供返回或面包屑。
- **可选模式**：保存视图、订阅、导出和自定义仪表板；适合高频分析任务。

### 可视化选择

| 分析问题 | 首选图形 | 避免或限制 |
| --- | --- | --- |
| 时间趋势 | 折线图、面积图 | 不混用不一致的时间粒度 |
| 类别比较 / 排名 | 条形图、柱状图 | 类别太多时改用表格或 Top N |
| 构成 | 堆叠条形图、百分比堆叠 | 饼/环图不超过 8 类，且不用于精细比较 |
| 分布 / 异常 | 直方图、箱线图、散点图 | 不用颜色作为唯一异常编码 |
| 关系 / 相关性 | 散点图、矩阵 | 避免把因果关系误表述为相关性 |
| 地理分布 | 地图 + 排名表 | 地图不适合精确量级比较 |

### 图表硬规则

- 标题说明指标、维度和时间，例如“近 30 天按区域的订单完成率”。
- 单位、精度、时间范围和数据更新时点可见。
- 同一维度跨图保持颜色语义一致；定量轴要说明是否截断。
- 不使用 3D 图；大数值需缩写一致，例如 `3.4M` 或 `340 万`，不要混用。
- 图表应提供表格或文本替代信息，确保色觉差异与屏幕阅读场景可理解。

## 大数据表格

### 默认结构

| 层级 | 内容 |
| --- | --- |
| 工具栏 | 结果数、搜索、筛选、列设置、密度、导出或批量操作 |
| 表头 | 列名、排序、筛选、说明与固定列策略 |
| 表体 | 可扫描的主字段、语义状态、辅助字段与行级操作 |
| 底部 | 分页/虚拟加载、总数、页大小、汇总或选中项操作 |

### 设计规则

- **硬规则**：为每列定义优先级；小屏或窄容器优先隐藏低优先级列，不能无提示截断关键字段。
- **硬规则**：数据超过一屏时固定表头；横向滚动时固定识别列和必要操作列。
- **硬规则**：批量操作显示已选数量、影响对象与取消选择入口。
- **推荐规则**：提供紧凑、默认、舒适三档密度，默认以桌面高密度但可读为准。
- **推荐规则**：长文本使用省略和完整内容提示；数值右对齐、状态与操作位置稳定。
- **推荐规则**：大数据量明确采用分页、服务端排序/筛选或虚拟化之一，避免假定全部加载。

## AI 数据助理

### 三种呈现形态

| 形态 | 适用任务 | 结构 |
| --- | --- | --- |
| 嵌入式助手 | 当前页面解释、筛选建议、快捷分析 | 侧栏或行内卡片，不遮挡主任务 |
| 分屏分析工作区 | 多轮分析、查询构建、图表与表格对照 | 左侧对话/任务轨迹，右侧可验证结果 |
| 沉浸式分析 | 复杂报告、跨数据源分析、长任务 | 全页工作区，保留上下文、历史和导出 |

### 最小结果单元

每一条 AI 数据分析结果至少由以下部分组成：

1. 结论或生成内容。
2. 数据来源、时间范围、指标口径与假设。
3. 结果形态：文字、指标、图表、表格或建议操作。
4. 用户控制：编辑、继续追问、重新生成、调整条件或拒绝。
5. 不确定性、失败或权限不足时的解释与下一步。

## 页面状态总表

| 状态 | 必需信息 | 用户可做什么 |
| --- | --- | --- |
| 初始 / 空态 | 任务价值、最小示例、入口 | 创建、导入、选择模板或查看示例 |
| 加载 | 正在加载的对象或阶段 | 等待、取消（长任务时）或查看已有内容 |
| 无结果 | 当前筛选条件与无结果原因 | 修改筛选、清空条件或创建数据 |
| 错误 | 发生位置、可理解原因、是否影响数据 | 重试、查看详情、联系支持或返回 |
| 无权限 | 受限对象和申请路径 | 申请权限或切换范围 |
| 过期 / 延迟 | 最后更新时间、影响范围 | 刷新、查看数据质量或继续使用旧数据 |

## 无障碍与可用性底线

- **硬规则**：小号文字前景/背景对比度至少 `4.5:1`；组件 hover、focus、active 与相邻色至少 `3:1`。
- **硬规则**：信息状态使用颜色之外的文字、图标、形状或结构表达。
- **硬规则**：键盘 Tab/Shift+Tab 顺序可预测；弹层打开时放置初始焦点，关闭时回到触发元素。
- **推荐规则**：动效在 150–300ms 之间，且尊重 `prefers-reduced-motion`。
