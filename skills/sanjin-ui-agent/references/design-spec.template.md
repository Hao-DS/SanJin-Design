# design-spec 模板（S1 产物）

仅在用户明确要求标准模式，或明确要求完整设计需求 / 设计规范时使用。默认快速模式不生成 `design/design-spec.md`。

复制下方内容到 `design/design-spec.md` 后逐节填写。章节顺序固定，与 G1 门禁一一对应，不要增删章节或另建结构。

**默认先按 `pipeline.md` 选档位。** 轻量档用 `design-spec.light.md`，不要先读本文件。本模板仅完整档使用。

填写规则见 `prd-to-design-spec.md`（G1 不过或任务流推不出时再读）。方括号里是填写指引，写完必须删掉；交付时残留 `[...]` 视为 G1 未通过。

## 填写注意

- 第 4、5 节是 S2 的施工图，写不细会在 S2 反复返工；第 6、11 节是 S4 交给开发的核心，写不清下游只能猜。
- 第 8 节只列**要做的**状态。清单越短越好，短说明范围清楚，不是说明想得少。
- 第 9、10 节不许合并。假设是我们已经定了的，待确认是必须别人定的，两者对下游的含义完全不同。
- 全文不出现组件名、颜色值、字号和像素间距。
