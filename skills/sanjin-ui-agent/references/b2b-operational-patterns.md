# B 端运营能力：权限、审计、性能与批量操作

本文件补充数据中台、BI、运营后台中的高风险和高数据量模式。组件实现仍须以当前技术栈 MCP / 物料为准。

## 权限与数据安全

### 硬规则

- 数据范围、字段限制、导出限制与操作权限不能只在失败后才告知。
- 无权限状态说明受限对象、原因和下一步；不得展示空白页。
- 敏感字段使用脱敏或最小展示原则；导出和查看完整值应受权限控制。
- 变更权限前显示原范围、新范围、受影响用户 / 资源和不可逆影响。

### 推荐规则

- 表格区分行级、字段级、操作级限制；不可用操作应给出原因。
- 提供申请权限、联系负责人或切换组织入口。

## 审计与可追溯

适用于权限、审批、数据配置、规则变更、发布与自动化任务。

| 事件 | 至少记录 | 用户界面要求 |
| --- | --- | --- |
| 创建 / 修改 | 操作人、时间、对象、前后值摘要 | 详情或审计页可查看 |
| 批量操作 | 选择数量、成功/失败数、失败原因 | 结果页或任务中心可追溯 |
| 审批 / 发布 | 审批人、意见、状态、版本 | 展示当前状态与历史 |
| AI 自动执行 | 请求、确认人、影响范围、执行结果 | 可定位、可重试或可撤销（适用时） |

## 批量操作

### 硬规则

1. 选中后显示已选数量、对象范围和取消选择。
2. 高风险操作必须确认；确认文案包含动作、数量和后果。
3. 异步批量操作给出进行中、成功数、失败数与失败明细入口。
4. 不允许因翻页、筛选、刷新而静默丢失选择；若会丢失，必须明确提醒。

## 数据表格性能

### 推荐规则

- 服务端筛选和排序时，界面应表明当前排序、筛选范围和更新时间。
- 长文本在列表中截断并可查看完整内容；不要用无限行高损害扫读效率。
- 横向滚动时固定对象识别列和操作列，并露出滚动提示。
- 大数据量避免“加载全部”；明确分页、虚拟化或增量加载策略。

## 状态演示建议

原型可通过开发环境状态切换器或 mock 菜单演示：

`normal | loading | empty | no-result | error | no-permission | long-text`

状态开关仅用于原型验证，不应当作为生产用户功能默认暴露。
