# design-spec 轻量模板（S1）

仅在用户明确要求标准模式或正式设计需求时使用。默认快速模式不生成 `design/design-spec.md`。

**先复制再填，不要先读 `prd-to-design-spec.md`。** 章节号与完整模板对齐，便于对照 G1；第 1、5 节轻量档不写。

适用：页面数 ≤ 2、无高风险动作，且不满足折叠条件。条件见 `pipeline.md`「产物档位」。任务流推不出来或 G1 自检不过时，再读规则全文，或改用 `design-spec.template.md`。

方括号是填写指引，写完删掉；残留 `[...]` 视为 G1 未通过。
