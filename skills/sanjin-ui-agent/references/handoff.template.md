# HANDOFF 模板（S4 产物）

仅在用户明确要求标准模式或正式交付说明时使用。默认快速模式不生成 `design/HANDOFF.md`。

**复制下方内容到 `design/HANDOFF.md` 后填写。** 轻量 / 折叠档用 `handoff.light.md`，不要先读本文件的填写说明。

这是交付给下游开发（人或 agent）的**唯一实现说明**，产物本体是可运行原型工程。

定位要分清：

| 文件 | 给谁 | 写什么 |
| --- | --- | --- |
| `prototypes/<name>/README.md` | 任何人 | 只写运行命令与页面入口 |
| `prototypes/<name>/evidence.json` | 复核者 | 组件取证记录 |
| `design/design-spec.md` | 产品与设计 | 需求本身 |
| `design/HANDOFF.md` | **下游开发** | 原型实现了什么、怎么接着做、哪些还不能信 |

HANDOFF 不是 design-spec 的复制。design-spec 说「要什么」，HANDOFF 说「原型里做成了什么样、和真实系统差在哪」。
