# 可交互原型交付与验证

适用于快速模式与标准模式的原型实现和浏览器验证。快速模式不因此生成 `design-spec.md`、`polish-log.md` 或 `HANDOFF.md`。

## 原型最低实现面

### 1. 主任务闭环（硬规则）

至少实现一条可操作链路：

```text
进入页面 → 识别上下文 → 填写/筛选/选择 → 执行主操作
→ loading 或进行中反馈 → 成功/失败 → 列表、详情或状态的结果落点
```

仅能点击按钮、只能打开弹窗、或只展示静态 mock，不算可交互原型。

### 2. 必要状态（硬规则）

按业务至少实现并可演示：

| 状态 | 最低内容 | 恢复操作 |
| --- | --- | --- |
| Loading | 正在处理的对象或区域 | 等待；长任务可取消 |
| Empty / No result | 当前范围与原因 | 创建、导入、清空或调整筛选 |
| Error | 用户能理解的原因与影响 | 重试、修正输入或查看详情 |
| No permission | 受限对象及原因 | 申请权限或切换范围 |
| Success | 完成的对象与结果落点 | 查看结果、继续操作或撤销（适用时） |

### 3. 高风险操作（硬规则）

批量修改、删除、审批、导出、权限变更、发布、自动执行必须展示：

- 影响对象数与范围
- 不可逆或副作用说明
- 确认 / 返回修改 / 取消
- 成功、失败及失败明细的落点

## B 端表格与性能

| 数据规模或形态 | 默认策略 | 规则级别 |
| --- | --- | --- |
| ≤100 条且无频繁刷新 | 前端分页或一次加载 | 可选模式 |
| 100–10,000 条 | 服务端分页、筛选、排序 | 推荐规则 |
| >10,000 条或高频滚动 | 虚拟表格 / 分段加载 | 推荐规则 |
| 宽表 | 固定识别列与操作列、列优先级、列设置、横向滚动提示 | 硬规则 |
| 批量操作 | 已选数量、浮动或邻近操作条、取消选择 | 硬规则 |

## 原型工程最小结构

```text
prototype/
├── src/
├── package.json
├── evidence.json
└── README.md
```

`README.md` 只写运行命令、页面入口、交互范围和已知限制；不要默认附加长篇设计报告。

## 运行时验收方式

浏览器里查问题**先测量，后截图**。截图只能说明「看起来不对」，测量能直接给出数值，成本低一个数量级且不会误判。

| 要确认的 | 用什么 |
| --- | --- |
| 列宽是否够、文字是否被截断 | 取元素的 `getBoundingClientRect().width` 与 `scrollWidth`，两者不等即溢出 |
| 滚动归属、固定区是否遮挡 | 取容器的 `clientHeight` / `scrollHeight` 与子块高度，核对相加是否超出 |
| 图片、异步内容是否真的加载 | 统计 `img.complete && img.naturalWidth > 0` 的数量，别靠肉眼看缩略图 |
| 样式规则是否生效 | 读 `getComputedStyle` 的具体属性值，不要从截图反推 |
| 标题 / 筛选 / 主表是否齐 | 取 `.page__head`、`.filter-bar`、`.kpi-row`、`.table-panel` 的 `left`，最大减最小 > 2 即未齐 |
| 整体视觉气质、交付给用户看 | 截图 |

截图配额：**每个页面状态最多 1 张**。连续两张内容相同说明改动没生效，先去查服务端返回的源码是不是最新
（`curl http://127.0.0.1:<port>/src/App.jsx`），不要继续截图。

截图超时或失败：停，只用测量交差，不要连着重试。浏览器后台标签会节流动画，抽屉/弹层「看起来没出来」先用 `getBoundingClientRect` 确认位置，不要当 bug 修三轮。

Hash 路由只改 `#` 时，模块可能不卸载、不重挂。验证换页后的状态，用带 query 的硬刷新（例如 `?v=2#/rules`），不要只改 hash 就判定「筛选没生效」。

## 验证命令

```bash
# 1. 依项目实际包管理器安装与构建
npm install
npm run build

# 2. 检查单栈导入、证据记录和视觉高风险模式
python3 <SKILL_ROOT>/scripts/validate_prototype.py \
  --project <prototype-dir> \
  --stack semi \
  --evidence <prototype-dir>/evidence.json
```

