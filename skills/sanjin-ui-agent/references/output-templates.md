## 快速评审清单

### 数据产品

- [ ] 首屏展示的是决策所需信息，而非所有可用数据。
- [ ] 用户可辨认当前数据范围、更新时间、口径和筛选影响。
- [ ] 表格列优先级、密度、固定列与加载策略已明确。
- [ ] 图表存在明确分析问题、单位、精度与钻取路径。

### AI 数据助理

- [ ] AI 内容和数据引用有明确标识。
- [ ] 用户能编辑、重新生成、调整条件或拒绝输出。
- [ ] 任何修改型或高风险动作均有影响范围和确认步骤。
- [ ] 失败不丢失上下文，且有可理解的恢复入口。

### 高保真原型

- [ ] 实现栈已确认，或已声明默认 Semi Design。
- [ ] 只使用选定栈作为实现库；组件 API 已由对应 MCP / 物料验证。
- [ ] 未把其它库的 API 或视觉皮肤硬拷进当前实现。
- [ ] 已遵循 `DESIGN.md`；交付前完成下方视觉验收。

## 视觉验收清单（硬规则 · 原型必过）

来源：`visual-quality.md` / `DESIGN.md`。任一项未勾选不得交付。

```text
[ ] 首屏仅：标题 / 筛选 / ≤4 KPI / 主表或主图
[ ] 仅 1 个 primary 实心按钮
[ ] 无渐变 Hero / 玻璃拟态 / 紫粉 AI 装饰
[ ] 无 chip 瀑布、双主按钮、彩色操作列
[ ] KPI 数字层级明显强于标签
[ ] 同级控件对齐，间距为 8/16/24
[ ] 用户要求的状态有文字（非纯色块）
[ ] 未增加用户未要求的 loading / empty 等状态
[ ] 仅使用选定实现栈组件
[ ] 颜色与圆角符合 DESIGN.md
```
