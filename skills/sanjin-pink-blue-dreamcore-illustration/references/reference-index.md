## 固定搭配

- 通用人物肖像：01 + 07；需要花朵/窗光时再加 05。
- 成年女性角色：09 + 01；需要窗光或室内氛围时再加 05。09 是角色特征参考，默认保留成年女性、大波浪长发、柔和暖肤、虹彩发丝与轻盈衣料等高层特征；除非用户明确要求同一角色，不复制具体面部身份、姿势、泡泡排列或服装细节。
- 动物肖像：07 + 01；不要复制鹿、眼镜、衬衣或花朵。
- 建筑/店面：06 + 08；需要大气透视或河岸空间时再加 02。
- 普通街区：08 + 02；单栋建筑成为主体时再加 06。
- 静物/饮品：03 + 04；需要窗边氛围时再加 05。
- 室内植物：05 + 03；第二张只提供透明材质与综合色彩，不复制水果组合。
- 校园阈限空间：08 + 02；建筑结构占比较大时加 06。现有参考只约束粉蓝媒介、空气、边缘与综合色，不提供走廊、楼梯或天桥的内容模板。
- 熟悉之地的温和错位：室外用 08 + 02，室内用 05 + 03，单栋建筑用 06 + 08。空间错位必须由场景规则和提示词原创构建，不得把参考里的街道、窗前树、桌面或住宅重新排列后冒充梦境。

使用时明确声明“这些是抽象风格参考，不是编辑目标，不复制内容”。当前参考集对粉蓝媒介和综合色覆盖充分，对阈限空间与逻辑错位的内容覆盖较弱；生成 G/H 配方时，参考图只回答“怎么画”，场景规则回答“空间为何像梦”。当 09 被用作女性角色参考时，额外说明它只提供约定的成年比例、发量、暖透肤色与虹彩边缘等高层特征，不复制具体面部身份、原图构图或服装。人物服装与妆造应由 [character-fashion-system.md](character-fashion-system.md) 生成原创设计，不从参考图或任何奢侈品牌秀场复制。生成后的质量判断也应回看所选参考的媒介身份、综合色域、阴影色、边缘处理与独立梦核证据，而非只比较是否出现泡泡或彩虹。
