# 质量门禁

逐项检查全画幅。先过“梦核身份”，再过“媒介身份”和“参考使用”三项硬门禁。任何一项失败都不得因为配色漂亮、主题正确或局部虹彩好看而直接交付。

## 核心项

- **梦核身份（硬门禁）**：假设移除粉蓝配色、泡泡和虹彩，画面仍须通过熟悉的阈限空间、醒后记忆般的语义模糊、一次温和的日常逻辑错位或有情绪的生活残留体现梦感。若只剩漂亮人物、柔光房屋或粉彩街景，判定为普通治愈插画。
- **媒介身份（硬门禁）**：缩略图下必须一眼读作柔雾空气喷绘式数字插画。平滑综合色域、软化结构边缘、局部绘制线性细节和珍珠分色同时存在；不得具有 DSLR 天空、真实砖墙/柏油微纹理、镜头景深、商业建筑摄影或写实渲染观感。
- **参考使用（硬门禁）**：生成时实际附加了 2–3 张题材相近的 style-references，并明确标为风格参考；若只用了文字描述，视为流程失败。
- **日常—梦境关系**：一眼可读的真实主体或日常场景，被小而明确的光学/材质偏离改变感受；不是只有粉蓝特效。
- **画幅与焦点**：比例服务人物留白、建筑高度、街景动线、阈限通道或静物结构；画面有且只有一个情绪焦点。焦点可以是人物/物件，也可以是门、转角、楼梯、走廊尽头或光线停留处。
- **记忆模糊**：主要空间与主体可辨，次要物件允许轮廓明确但用途不完全确定；模糊来自信息被省略、边缘融色和语义悬置，不是全画幅失焦、灰雾或低清晰度。
- **错位强度**：只保留一个主错位和至多一个弱辅助现象；异常约占视觉信息 10–20%，第一反应应是“似乎本该如此”，不是魔法奇观、谜题展示或惊吓。
- **空气**：水青、雾蓝或浅天蓝形成干净背景和空气透视；柔雾轻而有层次，未抹平主体和空间。
- **色彩**：综合色强度与题材匹配：强粉蓝 75–90%、记忆粉蓝 55–75%、阈限粉蓝 40–65%；近黑色不超过约 3%。颜色进入多个表面与阴影。记忆/阈限档可保留少量褪色现实色，但不得退回米白＋自然绿＋木棕＋柏油灰的摄影色盘。
- **亮度与肤色**：高调但面部、白衬衣、玻璃边缘和浅色建筑仍保留细节；肤色温暖透亮、不灰、不荧光、不橡皮。
- **人物造型（有人物时）**：人物超过 30% 时，缩略图下即可辨认一个完整主廓形，且结构、面料、妆发或主配饰中至少三项成立；人物占比 15–30% 时只需一个廓形特征、一个结构细节和一个妆发/配饰识别点；低于 15% 时服装必须服从环境，不得抢走阈限空间焦点。所有档位均不得复制品牌、秀场或明星造型。
- **服装可穿性（有人物时）**：剪裁、开口、接缝、重力、遮挡和动作关系可信；人物能完成坐、走、读书、持物等动作。高定感不应把日常场景变成红毯、婚纱或舞台表演。
- **虹彩**：透明物有背景、折射、边缘高光和遮挡关系；色彩如薄玻璃/珍珠，不是不透明塑料、铬金属或满屏油膜。
- **异常克制**：只有 0–2 种梦境现象，服务焦点；泡泡、蒸汽或闪点不遮挡眼睛、产品结构或叙事信息。
- **空间**：平视或略低、稳定垂直线和可信比例；街景、房屋、桌面或窗边仍可居住/使用，但空间关系来自插画构图，不靠镜头焦段、景深或摄影曝光建立。
- **表面**：柔雾空气喷绘插画质感，平滑渐变与局部细线并存；砖、路、木、叶与皮肤被适度简化。无相机微纹理、强 HDR、过锐、游戏 3D、厚油画、硬边矢量或商业棚拍亮泽。
- **文字**：无随机可读文字、乱码、logo 或水印；需要文字则已逐字核验，或预留干净位置给后期。
- **原创性**：未重演参考图中的具体卷发人物、菠萝与柑橘静物、咖啡杯校园、窗前树、鹿形人物、独栋住宅、河道桥或街景构图。

## 常见失败与修订方向

| 失败 | 优先修订 |
| --- | --- |
| 像写实建筑照片或咖啡店广告 | 保留建筑剪影，删除摄影/焦段/写实材质词；要求整帧转为 soft-airbrushed pastel digital illustration，简化砖、柏油、树叶和室内陈设，并重新附加 02/06/08 中的 2–3 张参考 |
| 只有粉蓝滤镜，主体仍像普通照片 | 不要继续加泡泡或水坑彩虹；先让粉蓝/粉紫覆盖墙、路、植物、白色物体和阴影，再做轻微边缘分色与插画化纹理简化 |
| 只是漂亮的粉彩治愈插画 | 加入一种可独立成立的梦核证据：阈限空间、记忆语义模糊、温和逻辑错位或有情绪的生活残留；不要先加泡泡 |
| 空间太正常、没有梦感 | 让门、路径、时钟、水迹、季节或次要物件产生一次轻微偏差，异常控制在约 10–20% |
| 空走廊或房间变成怪核 | 提高日光与可居住感，加入普通生活残留，删除黑暗、无限迷宫、监控和威胁视角 |
| 画面灰、白、发闷 | 移除 gray haze、faded、desaturated 等词；明确青空、粉色光漂移、暖白细节和有色阴影 |
| 太赛博或像夜店 | 删除霓虹、激光、黑背景、紫蓝强对比；改成扩散日光、浅黑位与普通生活场景 |
| 彩虹材质太塑料或太金属 | 缩小虹彩面积，指定透明玻璃、泡泡、蒸汽或水面，并要求背景折射和薄边缘高光 |
| 太甜、太幼或像贴纸 | 减少闪点和泡泡，保留真实建筑/器物/服装结构，采用自然表情与大留白 |
| 梦核变成恐怖空房 | 增加温暖日常锚点和柔亮环境；删除 liminal、empty、glitch、dread、creepy 等残留 |
| 主体看不清或过曝 | 降低 bloom 和高光，指定保留面部、玻璃轮廓和白色物体纹理 |
| 场景太满 | 只保留一个焦点、1–3 个日常锚点、1–2 个异常现象；把其余装饰移除 |
| 人像像商业海报 | 保留有辨识度的高定廓形，但放松姿势、减少镜头直视和强修容，把服装调整为可完成日常动作的秀场语言转译 |
| 服装普通、像模板人物 | 先重做主廓形与结构母题，再指定 2–3 种面料、一个妆发重点和一个主配饰；不要只追加闪粉或珠钻 |
| 服装像品牌复刻或红毯同款 | 删除品牌名、商标、字母纹样、标志性印花与可识别单品，保留更抽象的剪裁、体积、层次和材料逻辑重新设计 |

## 一次修订顺序

若首轮失败，按以下优先级只修最上游问题：

1. 缺少梦核身份：先增加阈限状态、记忆模糊、生活残留或一次温和逻辑错位。
2. 媒介不像插画：转换整帧媒介，删除摄影微纹理。
3. 色彩档位不合适或只在局部：选择强/记忆/阈限粉蓝并让综合色进入多个表面与阴影。
4. 场景过度商业或精致：删减陈列与装饰，让路径、轮廓、生活残留和留白先读。
5. 虹彩不足：只在梦核机制、媒介和综合色彩正确后，增加边缘分色或一个透明辅助现象。
