# 质量门禁

逐项检查全画幅。先过“媒介身份”硬门禁，再检查其余项目。若结果像照片、建筑可视化、写实 3D 或商业空间宣传图，直接判定失败；不能因为主题、构图或局部虹彩正确而交付。

## 核心项

- **媒介身份（硬门禁）**：缩略图下必须一眼读作柔雾空气喷绘式数字插画。平滑综合色域、软化结构边缘、局部绘制线性细节和珍珠分色同时存在；不得具有 DSLR 天空、真实砖墙/柏油微纹理、镜头景深、商业建筑摄影或写实渲染观感。
- **参考使用（硬门禁）**：生成时实际附加了 2–3 张题材相近的 style-references，并明确标为风格参考；若只用了文字描述，视为流程失败。
- **日常—梦境关系**：一眼可读的真实主体或日常场景，被小而明确的光学/材质偏离改变感受；不是只有粉蓝特效。
- **画幅与焦点**：比例服务人物留白、建筑高度、街景动线或静物结构；画面有且只有一个主要焦点。
- **空气**：水青、雾蓝或浅天蓝形成干净背景和空气透视；柔雾轻而有层次，未抹平主体和空间。
- **色彩**：粉蓝/粉紫综合色域覆盖约 75–90%；水青约 40–60%，暖粉/蜜桃/淡紫/奶油黄合计约 25–45%，近黑色不超过约 3%。墙、路、植物、衣物、白色物体和阴影都参与综合色染；不能保留米白＋自然绿＋木棕＋柏油灰的摄影色盘。
- **亮度与肤色**：高调但面部、白衬衣、玻璃边缘和浅色建筑仍保留细节；肤色温暖透亮、不灰、不荧光、不橡皮。
- **虹彩**：透明物有背景、折射、边缘高光和遮挡关系；色彩如薄玻璃/珍珠，不是不透明塑料、铬金属或满屏油膜。
- **异常克制**：只有 0–2 种梦境现象，服务焦点；泡泡、蒸汽或闪点不遮挡眼睛、产品结构或叙事信息。
- **空间**：平视或略低、稳定垂直线和可信比例；街景、房屋、桌面或窗边仍可居住/使用，但空间关系来自插画构图，不靠镜头焦段、景深或摄影曝光建立。
- **表面**：柔雾空气喷绘插画质感，平滑渐变与局部细线并存；砖、路、木、叶与皮肤被适度简化。无相机微纹理、强 HDR、过锐、游戏 3D、厚油画、硬边矢量或商业棚拍亮泽。
- **文字**：无随机可读文字、乱码、logo 或水印；需要文字则已逐字核验，或预留干净位置给后期。
- **原创性**：未重演参考图中的具体卷发人物、菠萝与柑橘静物、咖啡杯校园、窗前树、鹿形人物、独栋住宅、河道桥或街景构图。

## 常见失败与修订方向

| 失败 | 优先修订 |
| --- | --- |
| 像写实建筑照片或咖啡店广告 | 保留建筑剪影，删除摄影/焦段/写实材质词；要求整帧转为 soft-airbrushed pastel digital illustration，简化砖、柏油、树叶和室内陈设，并重新附加 02/06/08 中的 2–3 张参考 |
| 只有粉蓝滤镜，主体仍像普通照片 | 不要继续加泡泡或水坑彩虹；先让粉蓝/粉紫覆盖墙、路、植物、白色物体和阴影，再做轻微边缘分色与插画化纹理简化 |
| 画面灰、白、发闷 | 移除 gray haze、faded、desaturated 等词；明确青空、粉色光漂移、暖白细节和有色阴影 |
| 太赛博或像夜店 | 删除霓虹、激光、黑背景、紫蓝强对比；改成扩散日光、浅黑位与普通生活场景 |
| 彩虹材质太塑料或太金属 | 缩小虹彩面积，指定透明玻璃、泡泡、蒸汽或水面，并要求背景折射和薄边缘高光 |
| 太甜、太幼或像贴纸 | 减少闪点和泡泡，保留真实建筑/器物/服装结构，采用自然表情与大留白 |
| 梦核变成恐怖空房 | 增加温暖日常锚点和柔亮环境；删除 liminal、empty、glitch、dread、creepy 等残留 |
| 主体看不清或过曝 | 降低 bloom 和高光，指定保留面部、玻璃轮廓和白色物体纹理 |
| 场景太满 | 只保留一个焦点、1–3 个日常锚点、1–2 个异常现象；把其余装饰移除 |
| 人像像商业海报 | 放松姿势，减少镜头直视、强修容和时装细节，加入自然窗光/街景/生活动作 |

## 一次修订顺序

若首轮失败，按以下优先级只修最上游问题：

1. 媒介不像插画：先转换整帧媒介，删除摄影微纹理。
2. 色彩只在局部：扩大粉蓝/粉紫综合色域，压低自然绿、棕、灰、黑。
3. 场景过度商业或精致：删减室内陈列、路灯、桌椅和装饰，让轮廓与留白先读。
4. 虹彩过少：只在媒介和综合色彩已正确后，增加边缘分色或一个透明异常。
