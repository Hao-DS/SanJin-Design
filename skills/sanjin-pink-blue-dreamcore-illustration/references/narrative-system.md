# 叙事与情感系统

## 核心命题

把风格理解为一种温柔的错位：**寻常生活在极短的一瞬，暂时失去明确用途或因果，被还原成比现实更轻、更透、却不完全可靠的记忆。** 粉蓝空气与虹彩折光只是视觉表层；真正的梦核证据来自阈限状态、醒后记忆般的局部不确定、一次温和的日常逻辑失效，以及仍留在空间里的生活痕迹。不要用泡泡和闪粉代替情绪。

## 梦境情感

每张图选择一个情感发动机，不要混成关键词清单。

| 发动机 | 可见线索 | 避免 |
| --- | --- | --- |
| 晨间苏醒 | 窗光、刚散的水汽、未喝的饮品、清空的天空 | 日出大片、强烈逆光剪影 |
| 日常被照亮 | 家门、餐桌、花盆、通勤路、杯子被异常柔光照亮 | 无理由堆满奇幻物 |
| 私密成长 | 轻微不合身的衣物、个人物件、安静凝视、植物新芽 | 青春疼痛戏、时尚广告姿势 |
| 温柔独处 | 一个主体、可呼吸的空白、一件正在被使用的物件 | 空旷恐怖、抑郁黑暗 |
| 熟悉之地的异化 | 普通街道或房间保持可信，只让色光或材质略微偏离 | 末日、废墟、赛博城市 |
| 短暂停驻 | 水面、蒸汽、漂浮气泡、闪尘或彩色反射提示时间停一下 | 密集特效、魔法战斗或宏大奇观 |
| 温柔疏离 | 明亮的走廊、楼梯间、候车区或空教室暂时失去用途，留下半开的门、未收椅子或停住的窗帘 | 黑暗空房、无限迷宫、监控窥视、威胁感 |

## 一句话场景公式

人物主导：

~~~text
[主体] 在 [可信的日常地点] 进行/停留于 [一个普通片刻]；
[一次光学/空间/尺度/时间/语义错位] 让这个瞬间像从粉蓝色的梦里浮现。
~~~

环境主导：

~~~text
[一个熟悉的过渡空间] 暂时失去原本用途；
[1–3 个生活残留] 与 [一次温和错位] 让它像一段记不完整、但似曾到过的梦。
~~~

例：下课后的学生坐在安静操场边喝热饮；杯口升起的蒸汽折射成几缕轻薄的粉黄和淡紫色，远处教学楼沉在水青色雾光中。

## 梦核机制

每张图选择一种主机制；只有在不抢焦点时才加一种弱辅助现象。

- **光学错位**：虹彩反射、方向不一致的柔光、透明蒸汽、延迟半拍的水面倒影。
- **空间错位**：门、楼梯、窗或通道出现在略不合理但不危险的位置；路径似乎连接到天空、光或另一个普通房间。
- **尺度错位**：一个日常物略大或略小于正常尺度，保持材质与重力可信，不变成奇幻巨物。
- **时间错位**：不同钟表停在不同时间，水迹长久未干，室内外季节或光线轻微不一致。
- **语义模糊**：次要物件轮廓可辨却难确认用途；标牌留白、书页无字、远处陈设像被记忆省略。不要靠乱码文字制造模糊。

空间、尺度与时间错位必须来自普通世界，不引入怪物、魔法系统、未来科技或灾难叙事。

## 主体与异常的关系

- 主体不必执行戏剧性动作。望向窗外、端着杯子、整理花盆、走过街口、饮水、坐着发呆都足够。
- 日常锚点应是画面可信度的来源：一件衣服、一盏窗、一株植物、一条电线、一只玻璃器皿或一段湿地。
- 异常只负责改变感受，不负责抢走主题。人物和静物可偏光学/材质错位；走廊、楼梯、校园与街景优先空间、时间或语义错位，避免所有题材都依赖泡泡和虹彩。
- 它们要服从重力、空气与光的方向；即使“梦”，也应有真实尺度、边缘与遮挡关系。

## 情绪表达

- 以留白、视线、呼吸感、温和色温过渡和一个被凝视的日常物表达情绪。
- 保留一点安静与陌生感，避免“所有东西都在开心发光”。
- 允许约 10–20% 的轻微不确定或疏离：让观者产生“我似乎来过，但这里为何暂时没人”的疑问；空间仍须明亮、安全、可居住，不进入恐惧与失控。
- 角色可平静、略带好奇或轻微恍惚；不要惊恐、疯癫、夸张欢呼或过度摆拍。
- 非人物题材也需要情绪：让静物、房屋或植物拥有被晨光临时选中的感觉。
