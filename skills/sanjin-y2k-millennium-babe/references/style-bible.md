# SanJin-Y2K 千禧辣妹风格手册

## 美学锚点

Y2K 是世纪之交科技文化、流行文化与青年亚文化交汇形成的视觉体系。此技能专注其中的“千禧辣妹派”：借女性流行偶像、街头文化、早期互联网与消费电子审美，表达身体自主、个性自由与对传统审美的挑战。

时间锚点为 1998–2005 年。气质关键词：Teen Pop、MTV 时代、青少年时尚杂志、Celebrity Street Style、商场与夜店文化、早期互联网、CCD 快照、科技乐观主义、Retro Futurism。

## 人物脸部

用户未指定脸部或人物身份时，使用原创的冷艳灵动东方爱豆脸。只借用下列可见特征，不复刻、混合或暗示任何真实艺人；用户提供的长提示词仅作为脸部骨相、五官、妆容和真实摄影质感依据，不引入古风服饰、面纱或仙侠场景。

脸型与骨相：

- 窄鹅蛋脸，脸宽较窄，纵向比例略长，面部留白少、五官集中
- 额头中等偏饱满，发际线整齐自然；太阳穴轻微内收但不凹陷
- 颧弓不外扩，苹果肌轻微，面中过渡平整，法令区干净
- 下颌线清晰流畅，下颌角弱化；下巴小巧偏尖但不过度锐利

眉眼：

- 深灰棕色细长平眉，眉头保留自然毛流，眉峰不高，眉尾细而收紧
- 长杏眼偏狭长凤眼感，内眼角清晰，外眼角克制上扬，上眼皮薄、双眼皮较窄
- 下眼睑存在感清晰，卧蚕轻微精致；睫毛纤长成束但不过分夸张
- 视线可直视镜头、轻微侧看或短暂眨一只眼；眼神冷静但有反应，带一点试探、狡黠和即兴感；不做甜妹无辜眼和夸张愤怒表情

鼻唇：

- 细直秀气鼻，山根自然，鼻梁干净平直，鼻头小巧微圆，鼻翼窄，鼻孔不外露
- 中薄唇，唇峰清晰，上唇偏薄、下唇微饱满；可让单侧嘴角轻微上扬或嘴唇轻启形成顽皮感，不嘟唇、不做夸张大笑
- 唇色使用低饱和玫瑰棕、豆沙棕红或雾面红棕，中心略深、边缘柔化

皮肤与妆面：

- 冷白但自然的肤色，高完成度雾面丝绒底妆；保留细微毛孔、绒毛、浅淡眼下纹理、轻微肤色起伏和左右脸自然不对称
- 面中、鼻梁、鼻尖与眼下只做克制提亮；鼻侧、颧侧和下颌使用柔和自然修容
- 眼妆以深灰棕、冷棕、烟灰棕为主，内眼线完整，外眼线纤细锐利并轻微延长，下眼睑后半段适度加深
- 禁止油亮水光肌、塑料蜡像质感、过度磨皮、过度锐化、统一模板脸、空洞木偶表情

表情系统：

- 默认不是完全静止的冷脸，而是“冷感底色 + 古灵精怪微表情”
- 每张只选择 1–2 个微表情信号：单侧眉峰轻挑、眼神侧移后回看镜头、单侧嘴角微扬、嘴唇轻启、轻微眯眼、短暂眨眼、像刚想到坏点子般的克制笑意
- 面部左右允许非常轻微的不对称，眼神与嘴角变化必须互相呼应，避免僵硬贴图式笑容
- 表情幅度控制在时尚画报尺度，呈现聪明、俏皮、狡黠、有主见；禁止吐舌、鼓腮、夸张挤眼、鬼脸、卡通颜艺和幼态卖萌

发型以黑色或深黑棕长发为主，中分或轻微偏分，发量自然，发丝贴近面部两侧修饰脸型；少量碎发可以存在，但不遮挡眉眼。可按 Y2K 造型加入克制挑染、蝴蝶夹或细小金属发饰。

如果用户提供具体人物或要求保留身份，人物一致性优先于上述脸部规则，只优化允许变化的妆发与神态。

## 视觉维度

### 1. 廓形

高优先级单品：

- 低腰牛仔裤、低腰工装裤、低腰迷你裙、超短裙
- Baby tee、短款上衣、抹胸、挂脖上衣、紧身胸衣式上装
- 金属吊带、天鹅绒运动套装、微喇裤、修身短夹克
- 牛仔短裙、不对称上衣、局部镂空上衣
- 厚底鞋、厚底长靴、高筒靴

优先比例：

- 短上衣 + 低腰下装 + 修长腿部比例
- 紧身上装 + 迷你裙 + 长靴
- 修身短夹克 + 低腰微喇裤

允许适量不对称剪裁、非常规分割线、局部镂空和夸张比例。避免全身机甲化、纯 Techwear 或现代未来主义制服。

### 2. 材质

用“复古 × 未来”的材质冲突建立识别度：

- 未来向：金属银、Chrome、漆皮、亮面皮革、PVC、透明塑料、镭射面料、反光涂层、Mesh
- 华丽向：亮片、水钻、Glitter、缎面、丝绸
- 复古向：天鹅绒、水洗牛仔、弹力针织、人造皮草

有效混搭示例：牛仔 × 水钻、丝绸 × 金属、天鹅绒 × 亮片、皮革 × PVC、针织 × 镭射。材质要能被光线读出，避免只在文本中罗列而画面不可见。

### 3. 色彩

核心色：泡泡糖粉、荧光粉、婴儿粉、冰蓝、电光蓝、薰衣草紫、金属银、亮橙、酸性绿、白、黑。

推荐组合：

| 方向 | 配色 | 气质 |
| --- | --- | --- |
| Pink Y2K | 泡泡糖粉 + 银色 + 白色 | 甜美、明亮、流行偶像感 |
| Cyber Babe | 冰蓝 + 银色 + 黑色 | 冷艳、数码、复古未来 |
| Pop Princess | 粉色 + 紫色 + 水钻银 | 华丽、玩味、舞台感 |
| Street Y2K | 水洗牛仔蓝 + 白色 + 银色 | 街头、轻松、明星私服感 |
| Club Y2K | 黑色 + 荧光粉 + Chrome | 夜店、强势、反叛 |

允许高饱和视觉冲击，但避免莫兰迪、大地色、奶油米白、Old Money 黑白灰或现代极简配色成为主导。

### 4. 图案

只选 1–3 种作为点缀：蝴蝶、星星、爱心、火焰、部落纹样、金属图形、像素图形、数字网格、喷绘、水钻图案、抽象几何、千禧科技符号。

不要把服装图案扩张成 Vaporwave 海报、游戏 UI 或赛博朋克城市界面。

## 配饰与时代道具

高识别度配饰：彩色窄框或无框墨镜、大圈耳环、Choker、水钻项链、腰链、金属链腰带、蝴蝶或彩色发夹、腋下包、金属手袋、铆钉腰带、大体积戒指、银色首饰。

可少量加入 2000 年前后消费电子：翻盖手机、有线耳机、CD Player、Discman、MP3、透明塑料电子设备、早期数码相机。造型语言应厚实、圆润、半透明或银色塑料感，不能像当代智能手机和现代可穿戴设备。

## 妆发

发型：高马尾、双马尾、高位双马尾、蓬松卷发、长直发、粗挑染、面部挑染、锯齿分缝、蝴蝶发夹、两侧细碎发丝。效果应精心打扮、俏皮而张扬。

妆容以“冷艳雾面底妆 + 克制千禧闪光点缀”为主：皮肤保持冷白雾面丝绒质地，眼妆使用冷棕、烟灰棕并可少量叠加珠光银或冰蓝，细长平眉与纤细上扬眼线保持冷感；唇妆使用低饱和玫瑰棕、豆沙棕红或雾面红棕，不使用夸张粉色嘟唇。Y2K 的 Glossy 与 Shimmer 主要落在服装、首饰和眼妆细节点，不把整张脸处理成油亮水光肌。避免 Clean Girl、甜妹妆、现代韩系裸妆或高冷奢侈品妆面成为主体。

## 街头背景、姿势与构图

用户未指定场景时，直接使用下列已经固化的彩色街头视觉规范，无需参考图：

- 高饱和涂鸦墙、漫画式壁画或大色块街头艺术
- 粉、蓝、黄、青等彩色店铺立面和复古商业招牌
- 可见街道路面、斑马线、路沿或建筑边线，形成强烈透视引导
- 晴朗蓝天与日间硬光，或店铺霓虹与直闪共同形成清晰色彩分区
- 环境信息丰富但层级清楚，人物脸部和穿搭始终是第一视觉中心

招牌只作为图形化色块和氛围元素；除左上角规定的 `SanJin` 手写签名外，不生成其他可读品牌名、Logo 或水印。

这些背景规则必须仅通过文字提示词即可执行。不要主动要求用户上传参考图，也不要在生成调用中自动附带之前的参考图、历史图片或测试图。只有用户明确说“参考这张图”或要求复刻某个视觉维度时，才使用其提供的图片，并把参考范围限制在用户指定的维度。

默认构图采用街头时尚画报语言：

- 全身造型优先 35–50mm，中景或半身可用 50–70mm；透视自然，不把手脚放大到压过脸部与服装
- 平视或轻微低机位为主，只允许克制的轻微俯拍与倾斜；保持人物比例修长但真实
- 人物与背景保持适当距离，建筑、墙面和路面线条形成纵深，但不将镜头贴近人物
- 服装完整可读，脸部清晰，尽量保留手脚；裁切应像杂志版式而非意外截断

姿势采用专业画报模特语言，每张选择一个清晰、克制的造型：

- 单腿承重、另一腿自然前伸或轻微交叉，形成 relaxed contrapposto
- 身体轻微侧转，肩部与髋部形成柔和反向角度，头部回正看镜头
- 一手叉腰、一手自然下垂；或扶墨镜、持腋下包、整理头发、轻触项链
- 行走后的短暂停步、靠墙、倚靠栏杆、坐在台阶边缘或转身回望
- 表情与动作服务服装展示，手部松弛、肩颈打开、重心稳定

禁止大幅跨步、深蹲贴镜头、四肢冲向镜头、极端扭腰、双臂大幅上举、舞台舞蹈动作和过强鱼眼透视。姿势不应比服装和脸部更抢眼。

## SanJin 签名水印

所有成图默认加入唯一允许的作品标识：`SanJin`。

- 位置：左上角，距顶部与左侧各约画面宽度的 3%–5%
- 形式：小型自然手写英文签名，连贯但清晰，笔触干净利落
- 拼写：必须精确为 `SanJin`，保留大写 S 与 J，不得增删字母
- 尺寸：约占画面宽度的 6%–10%，不成为标题，不抢主体
- 颜色：根据背景对比选择低饱和白色、灰白色或暗红棕色；允许轻微透明，但不加描边、发光、厚阴影或底板
- 避让：不得遮挡脸部、头发轮廓、服装关键细节或高信息量招牌
- 除该签名外，禁止其他水印、Logo、品牌名和可读文字

生成后检查拼写、位置、数量和视觉权重。若签名错误，优先仅修正签名区域；无法局部修正时重新生成，不接受近似拼写。

## 摄影质感

默认使用 2000s compact digital camera / CCD photography aesthetic：

- 正面硬闪、轻微过曝、明亮皮肤高光
- 主体清晰、轻微数码噪点和克制的色差
- 快照感、狗仔抓拍感、明星街拍感
- 略显廉价但真实的早期数码质地

避免默认使用柔光奢侈品棚拍、电影级大面积氛围光、HDR、超现实锐化、现代手机人像算法或过度干净的商业摄影。

## 场景

首选：高饱和涂鸦街区、彩色商业步行街、漫画壁画巷道、街头潮流店门口。用户明确要求其他环境时，也可使用购物中心、霓虹便利店、街机厅、夜店、卡拉 OK、停车场、加油站、电梯、酒店走廊、卧室、试衣间、商场洗手间镜面、夜间城市街道、地下车库或复古未来室内空间。

可见元素：Chrome、透明塑料、镜面、霓虹灯、荧光灯、CD、海报、CRT 屏幕、老式汽车与千禧消费电子。背景服务于造型，不与人物争夺视觉中心。

## 防跑偏

禁止将本风格等同于“粉色 + 霓虹灯 + 未来科技”。重点排除：

- Cyberpunk、Vaporwave、Synthwave、Techwear、现代未来主义时装
- Kawaii Lolita、过度堆叠的 Harajuku、Coquette、Barbiecore
- Old Money、Quiet Luxury、Clean Girl、韩系极简
- 纯欧美夜店风、现代 Instagram 网红风、高冷奢侈品广告感
- 森系、文艺、清冷仙气、温柔奶油风

若画面偏赛博朋克，减少城市霓虹、机甲、LED、战术剪裁，增加低腰/紧身比例、水钻、牛仔、甜美元素和直闪快照感。若画面偏现代网红，加入早期消费电子、CCD 质地、千禧杂志感和不完美抓拍构图。若画面过度甜美，增加金属、皮革、铆钉、低机位或更自信的姿态。
