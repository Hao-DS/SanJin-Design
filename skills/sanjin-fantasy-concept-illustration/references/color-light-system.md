# 色彩与光线系统

## 核心公式

目标不是“多彩”，而是**蓝色统摄、洋红贯穿、暖色反冲、深色托光**。先让蓝色成为世界本身，再让可见的紫红/玫红色块贯穿不同空间层级，最后以橙黄制造跳跃焦点。

建议面积关系不是硬性像素配额，而是生成与验收时的层级：

- **约 50%**：钴蓝、群青、蓝紫和深靛蓝，覆盖天空/背景、主体暗部和承托面。
- **约 20%**：电光青、冰蓝或近白青色，承担跳跃高光、轮廓切口、空气刷痕和反射路径。
- **约 15%**：洋红、玫红、品红或紫红，必须形成明确色块，并跨越天空/背景、主体暗部、地面/前景中的至少两个区域。
- **约 15%**：珊瑚橙、朱橙、金黄或暖白，承担主光、地表、肤色、窗灯、果物或热源；不能全部压缩为一个小点。
- 自然绿、灰、褐仅在识别题材确有需要时少量出现，不得成为连接色或阴影主色。

## 推荐色板

| 功能 | 建议色 | 用法 |
| --- | --- | --- |
| 深暗基底 | 深靛 `#081A4B`、蓝黑 `#071331`、紫蓝 `#17124E` | 最深阴影、前景压暗、背景深处；不要用纯黑铺满 |
| 主体蓝域 | 群青 `#123FC4`、钴蓝 `#1557E8`、皇家蓝 `#2546A8` | 最大色面和中间调 |
| 发光蓝域 | 电光青 `#04D9FF`、亮青蓝 `#16BFFF`、冰蓝 `#9CF5FF` | 轮廓、反射、空气裂隙和局部高光 |
| 幻想过渡 | 洋红 `#F02CB6`、玫红 `#FF4F9A`、紫罗兰 `#7A37D8` | 云缘、背景能量、花朵、衣褶与倒影 |
| 暖色反冲 | 珊瑚橙 `#FF6A43`、金橙 `#FF9B32`、暖黄 `#FFD45A` | 视觉焦点、热源、地表、窗灯和肤色受光 |

不要机械复制十六进制值；生成时应描述色相功能与面积关系。

## 光线结构

每张图只选一个主光逻辑，但允许 1–3 处不符合真实光源的青、洋红或橙色跳光，以加强设计感：

1. **高位天光**：青蓝光从上方切入，适合树、人物、动物和静物；暖色集中在下方反射或肤色。
2. **逆光地平线**：暖橙/粉色从低地平线托起主体，青色轮廓光切边；适合风景、房屋和动物群像。
3. **街道湿光**：蓝色环境光统摄夜景，橙红窗灯与招牌反射在湿地上；标牌保持不可读，不自动加入赛博科技。
4. **物体内发光**：杯中热液、玻璃容器或魔法物体成为暖色光源；发光照亮相邻表面，不能像贴纸。
5. **侧逆光肖像**：青蓝背光勾勒发丝与肩线，暖色从下侧或正侧照亮面部；五官暗部仍保留色彩。

## 暗部与高光

- 最深暗部要有色相，通常是深靛、紫蓝或蓝黑；避免中性灰和褐黑泥色。
- 主要轮廓光服从主光方向；另可设置少量非物理青色或洋红高光，用断裂色块出现，不得整圈均匀描边。
- 高光面积越小，越能显得明亮；不要把主体外缘整圈描成同宽荧光线。
- 洋红既是青蓝与暖橙之间的桥，也是独立的设计色块；分布到至少两个空间层级，但不要铺成均匀粉雾。
- 白色只用于极少数最亮点；大多数亮部保持青、粉或暖黄的色相。

## 可变量与边界

可改变时间、天气、题材和主光方向。即使改成白天、室内或产品图，也必须保留蓝色统摄、跨区域洋红色块、深靛暗部、橙黄反冲和断裂电光层级。若用户明确要求另一主色，可迁移公式，但需说明这会降低默认风格识别度。

## 渐变压缩

- 把自然天空渐变压缩成 3–6 个相邻色块或宽刷痕，不做无痕过渡。
- 把主体的连续明暗压缩成亮面、中间色块、深靛暗面和少量跳光；避免完整写实光照模型。
- 远景不必系统性降饱和或泛灰；可以用更少细节、更大色块和局部同色合并来后退。
- 高光应“跳出来”而不是“慢慢变亮”：优先使用锐利断笔、刮擦边或突变色面。
