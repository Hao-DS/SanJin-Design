# 质量门禁

逐项检查全画幅与缩略图。先判断结果是否仍像“精致、史诗、写实的游戏 Concept Art”；若是，即使色彩正确也不得交付。任一核心项失败时先定向修订。

## 核心项

- **缩略图可读性**：一眼能认出主轮廓、主光方向和暖色焦点；不是颜色噪声。
- **表现主义身份**：第一视觉证据是大色块、粗宽刷痕、断裂边缘和人工色光，而不是精细材质、自然云朵、空气透视或史诗写实感。
- **细节密度**：相较常规精致 Concept Art，微观细节减少约 40–50%；树皮、叶片、毛发、碎石、草叶、裂纹和材质纹理均未成为主要完成度来源。
- **色块组织**：全画幅约 4–9 个大色块先读；单个树冠/云团/毛发组/衣褶组优先由 3–5 个主色块构成，而非渐变与碎笔触堆叠。
- **色彩统摄**：整体接近深蓝群青 50%、青蓝电光 20%、紫色洋红 15%、橙黄珊瑚橙 15%；蓝色参与主体与暗部，不只是背景。
- **洋红分布**：紫红、玫红或品红形成可见色块，并跨越天空/背景、主体暗部、地面/前景中的至少两个区域，不只围绕夕阳。
- **冷暖层级**：电光青承担跳跃高光、空气刷痕或反射，珊瑚橙/金黄形成足够可见的反冲色面；没有平均撒彩。
- **暗部质量**：存在足够深的靛蓝/蓝黑色块托住亮部；无死黑、灰褐罩染、浑浊黑位和抬灰阴影。
- **发光逻辑**：主光方向清楚，但存在少量断裂、非物理青色/洋红跳光；近白只出现在少量峰值，没有自然渐变式完整照明或均匀描边。
- **笔触方向**：1–3 条主导笔势可读；天空/背景、主体、地面/承托面三个层级中至少两个出现明显宽刷痕；无均匀碎刷。
- **边缘层级**：焦点最清晰，受光侧有锐利断边，背光侧有丢边；没有全画面同锐度。
- **空间深度**：空间可辨但有意识地压平；主要依赖遮挡、色块和明度分区，而不是自然空气透视、连续景深或真实材质尺度。
- **题材保真**：人物身份/肤色与五官可信，手部无明显错误；动物解剖正确；建筑透视稳定；产品关键结构和材质完整。
- **绘画性**：明显人工绘制痕迹与色块塑形；无摄影滤镜感、精致游戏原画感、平涂线稿、塑料 3D 或游戏引擎质感。
- **原创性**：未复制参考图的主体、组合、姿势、地标、房屋、动物阵列、咖啡杯、果物布局、云形或构图。
- **文字卫生**：无随机文字、乱码、logo、水印或签名；用户要求文字时逐字核验或留空后期处理。

## 常见失败与修订方向

| 失败 | 优先修订 |
| --- | --- |
| 像完成度很高的游戏 Concept Art | 一次性削减约 40% 微细节、把渐变合并为色块、把自然背景重画成宽刷痕；不要只追加“painterly” |
| 壮丽史诗但不够表现主义 | 压平景深，减少真实空气透视与物理光照，扩大洋红/青蓝跳色色块，保留明显人工笔痕 |
| 蓝色只在背景 | 把主体暗部、中间调和反射统一纳入群青—深靛系统 |
| 洋红偏少或只在夕阳附近 | 在天空/背景、主体暗部、地面/前景中至少再选两个区域加入明确紫红—玫红色块 |
| 满画面都亮 | 扩大深靛色块，删减泛光，只保留一个主光和少量峰值 |
| 像赛博朋克 | 删除科技标牌、线路与无因霓虹，恢复自然/日常题材和绘画性光源 |
| 像 vaporwave 渐变 | 改为有边缘、有方向、有尺度变化的厚涂色块 |
| 像日系平涂 | 弱化线稿，增加色块体积、丢边和可见大笔触 |
| 冷暖过于平均 | 把橙黄缩回焦点，把洋红作为过渡而非整层滤镜 |
| 暗部发灰发脏 | 移除灰褐与全局雾层，改用纯净深靛、紫蓝和蓝黑 |
| 只有颜色没有体积 | 明确主光方向，让笔触沿形体转折，建立亮面—中间调—暗面 |
| 笔触太碎 | 合并背景和中间调，保留 1–3 条主导动势，只在焦点细化 |
| 云仍像真实云 | 合并成 3–7 块巨大、拉长、断裂的刷痕，统一运动方向，删除蓬松体积渐变 |
| 树冠/毛发仍逐片逐根 | 每组压缩为 3–5 个深靛、钴蓝、青蓝与洋红主色块，使用拖拽破边 |
| 前景过细 | 压缩为 4–6 个大色块，统一岩石色相，删除大部分碎石、细草与裂纹 |
| 主体融进背景 | 强化轮廓负形、局部明度差与受控青色边缘光 |
| 人物/动物/产品失真 | 降低风格强度在关键结构上的覆盖，先修身份、解剖、接口与比例 |
| 参考图残留 | 更换构图骨架、主体姿态、道具关系和云形，只保留抽象色光笔触规则 |

## 交付前记录

记录：输入角色、题材配方、主轮廓、4–9 个大色块、主导宽笔势、50/20/15/15 色彩校准、洋红分布区域、非物理跳光、空间压平方式、删减的微细节、比例/像素、保留项、一次主要修订及未解决限制（如有）。
