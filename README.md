# SanJin-Design

这是一个用于整理、沉淀和分享设计相关 Skills 的长期项目，主要收录我在日常设计实践中总结出的视觉风格、设计方法、工作流程与经验规范。仓库中的每个 Skill 都围绕一个相对明确的设计主题展开，例如视觉风格定义、界面设计、版式设计、配色策略、字体搭配、品牌表达、图形语言、动效原则、设计评审以及设计稿优化等。它们并不只是简单的提示词集合，而是尝试将设计过程中较为抽象的审美判断、思考方式和实践经验，转化为更清晰、可执行、可复用的指导规则。

建立这个仓库的初衷，是希望把分散在不同项目、设计稿和个人经验中的知识逐步整理出来，形成一个能够持续积累和迭代的设计知识库。许多设计经验往往存在于设计师的直觉之中，能够感受到什么是好的，却不一定容易准确描述。通过编写 Skills，我会尝试拆解这些直觉背后的原因，明确一种风格适用于什么场景、由哪些视觉元素构成、需要遵循哪些原则，以及哪些常见做法可能破坏整体体验。这样的整理过程既是对个人设计经验的复盘，也有助于让设计方法被更稳定地理解、复现和应用。

仓库中的内容会随着实际项目和使用反馈不断更新。新的设计风格、案例分析和工作方法会被逐步补充；已经存在的 Skills 也会根据实际生成效果、设计质量和使用体验持续调整。对于复杂的设计方向，除了核心说明之外，还可能包含风格指南、参考图片、色彩方案、字体建议、布局规则、组件示例、检查清单以及其他辅助素材，帮助使用者更完整地理解某种设计语言，而不是只模仿表面的视觉特征。

这个项目既服务于我个人的设计工作，也希望能为设计师、产品经理、开发者以及对 AI 辅助设计感兴趣的人提供一些参考。你可以将这些 Skills 用于设计灵感探索、视觉方向制定、界面生成、方案优化、设计评审或团队协作，也可以根据自己的项目需求进行修改和扩展。不同 Skill 之间可能拥有不同的风格倾向和适用边界，使用时建议结合具体的产品目标、品牌特征、内容结构与目标用户进行判断，而不是机械地套用固定形式。

设计是一种需要持续观察、实践和反思的能力。这个仓库不会被视为一套已经完成的标准答案，而是一份不断生长的设计笔记和方法集合。我希望通过长期维护，将零散的灵感逐渐转化为系统化的经验，将个人判断转化为可以交流的设计语言，并探索 AI 如何更准确地理解和执行具有审美要求的设计任务。欢迎浏览、使用并提出建议，也期待这些积累能够为更多设计实践带来启发。
